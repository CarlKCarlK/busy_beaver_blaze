# Sound preview

Experimental sound build from [feature/wasm-sound](https://github.com/CarlKCarlK/busy_beaver_blaze/tree/feature/wasm-sound), source commit `ed37fa266d4a6bd236e1689e67bbdadb928a9b1a`.

[Open the preview](https://carlkcarlk.github.io/busy_beaver_blaze/previews/sound/#program=bb10&colorBy=state&sound=states&earlyStop=false&run=true). The visualization starts automatically; use Enable sound if the browser blocks audio autoplay.

This directory is a static snapshot of `docs/v0.2.8` on the feature branch, with a preview heading and state sound selected by default. The default site redirect and the regular v0.2.8 files are unchanged. Refresh this directory from the feature branch to publish another preview snapshot.
